# 三张表说明（小白版）

这个项目的核心不是图片，而是三张"表"（JSON 文件）。图片只是最后根据这些表画出来的结果。

## 1. storyboard.json —— 故事表（整个漫画一张）

回答：**这个故事讲什么？每张图里有谁？说什么话？**

- 由 AI 根据你输入的主题自动生成。
- 人可以随时打开改对话、改说明文字。
- 里面的 `scene_id`、`character_id` 是"身份证号"，其他表都靠它们互相对上。

## 2. character.json —— 人物表（每个角色一张）

回答：**这个人长什么样？穿什么？参考图在哪？**

- `appearance` / `clothing` 用英文写，因为画图 API 对英文理解更稳。
- `style_prompt` 是拼好的画风提示词，每次画图都会带上，保证风格统一。
- `reference_images` 是 AI 画好的标准照（正面、全身、侧面），以后每画一张新图都拿它当参考——**人物不走样就靠它**。

## 3. scene.json —— 排版表（每张图一张）

回答：**这张图里，背景、人物、气泡、文字各放在哪？多大？**

- 坐标是像素，画布固定宽 1080（公众号长图标准宽度）。
- 每个东西都是独立的一层（`layers`），所以审核时说"把人物往左挪一点"，只改一个数字就行。
- `status` 记录这张图进行到哪一步：`draft`（草稿）→ `generated`（已生成）→ `approved`（审核通过）。

## 三张表的关系

```
storyboard.json ──引用了──→ character.json（谁出场）
      │
      └── 每个 scene ──生成──→ scene.json（怎么摆）
                                    │
                                    └── 最终拼出长图 / PPTX
```

改字 → 改 storyboard/scene 里的 text；挪人物 → 改 scene 里的 x/y；
人物长得不对 → 重新生成 character 的参考图。**都不用重画整张图。**
