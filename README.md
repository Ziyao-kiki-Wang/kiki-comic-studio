# AI 漫画工坊

FastAPI + React 的漫画工作台：主题与角色 → 故事表 → 角色确认 → 分镜生成 → 气泡编辑 → 长图 / 创意拼版 / PPTX 导出。

## 本地启动

在项目根目录创建 Python 虚拟环境并安装后端依赖；已有 `.venv` 可直接使用：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

在根目录 `.env` 配置 `OPENAI_API_KEY` 和 `OPENAI_BASE_URL`。也兼容原有 `spike/.env`，已有环境变量优先。模型配置位于 `server/config.py`；请确认所用服务支持对应的文字与图片模型。

分别在两个终端启动：

```powershell
# 项目根目录：后端
.\.venv\Scripts\python.exe -m uvicorn server.api.app:app --host 127.0.0.1 --port 8000
```

```powershell
# 项目根目录：前端
cd web
npm install
npm run dev -- --host 127.0.0.1
```

打开 http://127.0.0.1:5173 。前端默认请求 http://127.0.0.1:8000；使用其他端口时，可通过 `VITE_API_BASE` 指定后端地址。生产静态资源构建命令为 `cd web` 后执行 `npm run build`。

已安装依赖时，也可以在项目根目录执行 `powershell -ExecutionPolicy Bypass -File .\scripts\start-studio.ps1`，在后台启动缺少的前端和后端服务。入口固定为 `http://127.0.0.1:5173/`，日志保存在 `output/logs/`；已运行的服务会复用。链接在这台电脑上访问，关闭服务或重启电脑后需重新运行启动脚本。端口冲突时会明确报错，不会悄悄换成另一个端口。

## 使用流程

创建故事时，模型接收逐张标明角色编号、名字和身份的上传参考图，在 `english_desc` 中记录可见外观；外貌由图片决定，故事身份由用户设定。服务需要支持 Chat Completions 图片输入（见 [官方说明](https://developers.openai.com/api/docs/guides/images-vision?api-mode=chat)）。

修改剧情或出场人物后，点击生成会先结合角色图整理受影响分镜的英文画面描述，清理旧动作和旧人物，不覆盖用户的剧情、台词或其他分镜。成功生图后才保存整理结果；失败保留原故事和图片版本。`scenes/<scene_id>.json` 的 `prompt_preparation` 记录对应输入与画面表现要求，未改动画面要求时复用；只改台词或排版不调用故事模型，最终提示词和附件清单保存在 `generation_history`。

默认画面表现参考广告科普漫画：一个明确的视觉中心、夸张表情和动作、有大小层次的物品组合，以及少量惊讶线、汗滴、警示等漫画符号。关键手机或告示牌可以放大到接近人物大小，不需要逐格额外下令；模型结合相邻格构图，在巨物特写、人物对峙、物品组合、围绕告示讲解、果断行动等方式之间变化。它改变画面表现，不改变角色形象、出场名单和剧情事实，不凭空添加金额或收益率。透明模式允许孤立的漫画符号，台词气泡、旁白和章节标题仍由排版添加。规则集中在 `server/core/style_prompts.py`，分别用于故事生成、分镜整理与最终生图；明确指定真实比例或克制构图时优先遵循用户要求。

旧项目在下一次重跑受影响分镜时整理旧提示词，已生成的图片不会自动重画；如果这一格只有默认表现要求变化，会同时提供当前版本已采用的改图命令，保留用户已经确定的内容。画面要求已被用户另行修改时，以当前输入为准。

手机、桌椅、宣传单等物品直接根据场景地点、剧情与动作随画面生成，无需勾选道具或单独生成道具参考图。故事模型将必要物品和接触关系写入画面描述，反复出现的物品通过描述保持外观一致。已有项目的道具数据与文件保留，但不参与新生成的提示词和参考图选择。上传人物保持原画风，所选风格仅协调环境与物品；需要指定某件物品外观时，可补充剧情或使用「本格专属参考」。已有错误画面可在「画面精修」重跑对应格，历史版本保留。

人物标准照和分镜生图均要求完整头发、发髻与发饰入画，并在最高处上方至少预留画面高度 8% 的空间；画面拥挤时缩小主体或退远镜头。分镜默认完整人物，桌椅的自然遮挡可保留；明确要求半身或特写时仍保留完整头部。此要求同时用于故事生成、修改后的提示词整理和最终生图。已被原图截断的部位需要重画或按要求改图，重新合成与排版不会补出缺失内容。

工作台最左侧提供四个固定入口：**分镜制作 → 画面精修 → 作品排版 → 贴纸装饰**。分镜制作确认角色、编辑故事并生成画面，下方「分镜预览」集中查看结果、标记通过；AI 改图、本格参考、重跑与版本切换统一放在画面精修页，精修页有分镜缩略图、画布和属性面板。修改尚未保存时，离开编辑页会提示。

分镜制作的角色确认与故事设置固定纵向排列。故事设置下方的「生成漫画」会先保存，再启动生成；保存失败不会启动任务，生成失败可在原处重试，也可选择「仅保存故事」。默认背景模式统一应用到各格，右侧用同一小女孩展示完整场景与透明主体。每格可以细调场景地点、出场人物和「本格剧情与动作」（中文，描述谁在做什么动作），也可展开补充画面细节；物品由剧情自动决定，生成前按最新剧情整理冲突的描述。地点、人物、剧情或画面描述的变动会标记对应分镜需要重画，单纯修改台词、旁白只更新合成。

手机与屏幕不再逐格预先勾选：故事中提到手机时随画面绘制，按叙事重点选择自然持握、夸张巨物或独立放大展示。生成后进入「画面精修」，可在「手机屏幕特写」中填写屏幕内容并生成特写图，叠加在分镜上拖动、缩放或隐藏；按新描述重新生成特写不影响画面本体。分镜小标题用于排版中的章节标题；只有当前选择「问答科普」模板时，才显示问题输入框（问题在上方，旁白作为解答）。

### 字体、专属形象与最后装饰

- **字体库**：已接入用户提供的字体包，包含思源黑体 7 个字重、思源宋体 7 个字重、微软雅黑常规 / 粗体 / 细体，共 17 款。思源黑体和思源宋体替换原来的方正占位项，按真实名称显示。共享字体位于根目录 `fonts/`，所有项目直接可用；微软雅黑从 TTC 提取首个字体为 TTF，供浏览器与 Pillow 使用。前端仅加载当前选中的字体。仍可上传 TTF、OTF、TTC 替换当前项目中的字体，单个最多 32 MB；项目上传优先于共享字体。替换已使用字体后需重新合成。
- **本格专属参考**：在画面精修页上传形象，可追加参考，或选中本格某个角色，仅替换这一格的角色参考。修改图片或重跑时使用，不影响其他格。模型可能调整参考图细节；需要保持原图时使用精修页的“单格贴图”。
- **单格贴图**：上传 PNG、JPEG、WebP，叠加在本格画面上，支持拖动、缩放、旋转、透明度、翻转和层级调整。保存后进入单格图、长图及 PPTX。
- **艺术字标题**：排版页支持简洁、描边、柔和投影、立体浮雕，文字可以继续编辑；支持字体、字号和对齐。也可上传已设计好的标题图片，替换文字标题。标题图片的内容仍需通过替换图片修改。
- **最后贴纸装饰**：内置 155 张独立透明贴纸，分为花草、星空天气、爱心、蝴蝶结、水果、箭头、美食、手账、花边、日常、相框 11 组。选择区只展示图片，点击即可添加，也可展开“我的上传”使用自己的素材。支持位置、尺寸、旋转、翻转、透明度与层级调整。素材和布局独立保存，重新打开仍可调整。保存并完成生成后下载 1080 px 宽的正式长图，导出不会包含选框；重新排版后应检查贴纸位置。

内置贴纸文件在 `web/public/sticker-assets/`，选择目录在 `schemas/stickers.json`。首次使用时通过现有素材接口存入当前项目，同一贴纸重复添加会复用素材；导出继续读取项目素材，因此不依赖临时文件。`scripts/extract_sticker_sheets.py <原始图片目录>` 可从本次提供的 11 张透明图集重新拆分，保留原图颜色、描边及阴影，相框中心保持透明。
- **避免下载旧成品**：排版或分镜变化后，旧长图会明确标为需要更新，重新生成后才能下载最新版。

共享字体来自用户提供的 `comic-fonts.zip`，原始说明保留在 `fonts/README.md`；此说明作为来源记录，实际字体名称和字重以 `schemas/fonts.json` 为准。项目上传的字体和图片独立保存。PPTX 保留可编辑文字，按字体内部名称和实际字重导出，不嵌入字体文件，打开 PPTX 的电脑需要安装所选字体；PNG 和网页预览直接读取项目字体或共享字体。

### 原有生成与编辑流程

1. **主题与角色**：创建项目时可上传最多 6 个现成漫画 / IP 角色（PNG、JPEG、WebP，单张最多 8 MB），填写名称、角色职责及外观说明；也可不上传，由系统创建角色。上传图保存为参考图，后续人物生成会跳过它。替换参考图时保留历史版本，并提示相关分镜需要重画。
2. **确认形象**：故事表生成后，在工作台生成缺少的角色形象，检查或替换参考图，点击确认，再生成分镜。已有项目可继续编辑。
3. **背景模式**：创建时选择完整场景或透明主体，在故事设置中统一调整。透明模式由生图模型直接输出透明背景 PNG，根据剧情将人物、桌椅、沙发、手机和参与情节的物品作为完整组合，外围及物品间空隙透明。生成后直接进入预览、气泡排版和导出，不再进行本地去白底或模型抠图。提供透明原图和带气泡的透明分镜 PNG。
4. **气泡编辑**：提供 10 种可视外形和 6 套配色，包含日常圆角、椭圆、长短交错的爆炸尖角、云朵、手绘、柔软圆角等；可单独调整底色、文字色、描边色和 0–12 px 边框（0 表示无边框）。两种爆炸和旁白无尾巴；其余样式可选上、下、左、右出口，拖动蓝点调整出口位置，拖动橙点改变尖端指向。支持台词、字号、宽度、位置和换行，双击气泡可定位到台词输入框。特写框可移动、缩放和隐藏。
5. **作品排版**：选择 17 套模板（11 套经典长图、6 套创意拼版），已生成的项目会加载实际排版样张。设置主题色、标题、副标题及结尾文字，实时查看合成预览。标题顶部留白（0–400 px）、标题底部留白、标题行距、全篇字距和正文行距均可调整；成品顶部不再附加模板名称或“漫画故事”等自动标签。统一格间距范围为 0–400 px，也可独立设置任意相邻两格的距离。改统一间距会清除单独设置，恢复统一排版。点击保存后生成正式长图。
6. **导出**：单格编辑页可直接下载原图、透明素材、含气泡画面、含旁白单格和屏幕素材；工作台提供长图及 PPTX。PPTX 的台词为可编辑文字，气泡轮廓为 SVG 图形。气泡轮廓、换行和位置随编辑器保存；改动后需重新合成再导出。

7. **按要求改图**：在逐格编辑填写中文修改命令，点击“按要求修改图片”。系统把当前原图作为第一张编辑参考，保留历史版本并记录实际命令；只在修改范围内加强表现，保留其他构图与细节，编辑失败时保留当前版本。原有“重跑”仍可按故事描述重新绘制。
8. **手机构图**：手机和屏幕随人物、物品一起生成，按剧情主动选择放大展示或自然持握，不再逐格预先设置。画面生成后如需屏幕特写，在画面精修的「手机屏幕特写」中描述屏幕内容并生成，特写在画布中可移动、缩放、隐藏，也可按新描述重新生成。

首页左侧显示项目列表，支持搜索和新建项目。选择项目后，列表自动收起，左侧改为“分镜制作、画面精修、作品排版、贴纸装饰”四个创作步骤，点击“返回项目列表”再显示项目列表。步骤标题为 26px 圆润字体，配合彩色图标与圆角卡片；窄屏通过顶部“项目”或“创作步骤”按钮展开左侧导航，选中后自动收起。离开前，未保存的修改仍会提醒。新建页右侧随格数切换显示对应数量的分镜示意，同时展示 8 种画风的实图样例；点击缩略图也可选择画风。样例以用户提供的丸子头、奶油色开衫小女孩为统一原型，使用内置 image_gen 生成八种画风，内置于 `web/public/style-previews/girl`；原始参考与完整提示词集保存在 `output/imagegen/style-preview-girl`。切换示例不调用生图接口。实际故事和画面按用户主题创建，示例格子不限制最终排版。

### 自由排版与连续编辑

画面精修中，气泡轮廓与对话文字是两个独立对象。点击轮廓或右侧“气泡轮廓”选中外形，拖动选框边角可压缩、拉伸，上方手柄可旋转；文字保持独立。点击文字或“对话文字”可单独移动透明文字框，左右边框调整换行宽度，角点调整字号，也可设置居左、居中、居右和独立旋转。“文字重新适配气泡”会恢复自动排版和气泡默认比例。

旁白可直接在画布中拖动，也可点击“移动旁白”选中并调整字号、对齐及旋转。自定义旁白位置保存在分镜中，单格 PNG、长图和 PPTX 都保留该位置；长图模板不再重复添加同一条旁白。点击“恢复旁白默认位置”可恢复图下旁白及模板的正文排版。

右下角固定显示“保存”和“保存并编辑下一张”，最后一格显示“保存并进入长图排版”。保存只重新合成当前分镜，不调用生图接口；全部分镜已就绪时同时更新长图，其余分镜未完成时也可保存当前格。保存或合成失败时留在当前格并显示原因。

桌面版长图编辑器的模板、预览和设置栏分别滚动。设置栏与预览之间的分隔线可左右拖动，或聚焦后按左右方向键调整宽度；滚动设置时可继续对照标题预览。

| 简洁卡片 | 圆角卡片、清晰留白 |
| 杂志分章 | 留白标题与分章结构 |
| 漫画分镜 | 粗线边框、漫画页视觉 |
| 贴纸手账 | 柔和纸色、贴纸和胶带装饰 |
| 事件时间轴 | 时间轴串联事件经过 |
| 问答科普 | 问题标题与对应画面 |
| 知识笔记 | 横线纸、笔记式标注 |
| 整幅海报 | 大画面、较少装饰 |
| 重点提示 | 醒目提示条、重点信息块 |
| 国风长卷 | 暖纸色、长卷装饰与章节 |

| 杂志跨栏 | 首格大图，后续双栏 |
| 手绘拼贴 | 点阵纸、错落照片卡和手绘线条 |
| 电影胶片 | 深色双栏镜头与两侧胶片齿孔 |
| 横向连环画 | 每行最多三格，从左往右阅读 |
| 方形画廊 | 方形画框、柔和底色与双栏展墙 |

“漫画排版工坊”左侧可筛选全部、经典长图或创意拼版。新款追加在原有模板之后，使用当前分镜进行排版，不调用生图服务。图片按原比例完整缩放，不裁切；手动摆放在图内的旁白保留原位，其他旁白进入模板文字区。奇数分镜的最后一格居中，横向连环画超过三格后自动另起一行。多栏版式按从左到右、从上到下阅读，支持统一行间距与逐行间距；同一行原有的单格间距取最大值，修改该行后统一应用到同行各格。

右侧“上下留白”可独立设置顶部、底部外侧留白（0–20 厘米），支持滑块、小数输入及一键清除。留白添加在整张模板外侧：上方在标题之前，下方在结尾图文之后，模板内部间距另行保留。默认按成品宽 20 厘米换算，也可在“设置成品宽度”中改为 5–100 厘米；PNG 仍为 1080 像素宽，同时写入对应的打印分辨率。屏幕预览会缩放，打印时选择原尺寸才能保留设定的厘米数。设置保存在 `long_layout.margin_top_cm`、`margin_bottom_cm` 和 `print_width_cm`，所有模板的预览及导出使用相同换算。贴纸使用最终页面坐标，修改留白后可在贴纸装饰页调整位置。

“国风长卷”的两侧双竖线贯穿顶部和底部留白，延伸到页面边缘；留白调整不改变分镜尺寸。

“背景底色”支持常用色、自选色和 0–100% 透明度（0% 为实色，100% 为全透明），可一键恢复当前模板默认底色。颜色和不透明度保存为 `long_layout.background_color` 与 `background_opacity`（0–1）；只改变页面底色，图片、文字、卡片和装饰保留各自外观。预览、保存和 PNG 下载保留真正的透明通道。切换模板时，自定义底色继续保留；恢复默认后会跟随模板。

每个结尾文字或图片块都有“与上方内容间距”，范围 0–20 厘米，与成品宽度使用相同换算，保存为 `footer_blocks[].gap_before_cm`。上传图片和 AI 生成图片插入后使用相同控件，调整只移动当前块及后面的内容，不改变前面的分镜。旧项目未设置此值时保留原有 24 像素间距，页面最底部距离仍由“底部外侧留白”控制。

小标题样式、艺术字标题、结尾图文和贴纸均可与创意拼版一起使用。成品仍是单张 PNG，高度随分镜数量和文字多少自动变化，不是固定页数的 PDF；内部仍使用 `long_layout` 和 `output/长图.png`，兼容已有项目与下载入口。PPTX 继续使用原有逐格导出方式。

## 数据与透明图片

项目保存在 `projects/<project_id>/`，以 `storyboard.json` 为故事数据，`scenes/<scene_id>.json` 为分镜编辑状态。角色、场景版本、屏幕特写、透明主体及合成结果分别存储；长图为项目目录下的 `output/长图.png`。用户图片在 `assets/`，字体在 `fonts/`，素材记录在 `assets.json`。单格原样贴图保存在场景布局的 `overlays`，最终贴纸保存在故事表的 `long_layout.stickers`。

透明场景的生成、参考图生图和按要求改图都显式传入 `background="transparent"`、`output_format="png"`，完整场景使用 `background="opaque"`。新人物标准照同样直接请求透明 PNG；上传形象原样保存。可选的“生成透明参考图”使用生图模型编辑原图，另存透明副本。模型仍使用 `server/config.py` 中配置的 `gpt-image-2`；图片服务需要支持透明背景参数。保存时检查文件完整性，以及透明输出是否同时包含全透明区域和可见内容，不修改模型返回的像素。接口返回白底、假棋盘格或全空图片时明确报错，保留已有文件。

透明场景的 `foreground_url` 直接指向版本池中的透明原图，预览和 PNG / PPTX 导出使用同一文件。旧项目中已带透明背景的原图可直接复用；旧白底图在故事设置下方点击“生成漫画”时由模型生成透明新版本，旧版本保留。单纯“重新合成”不会调用生图接口，遇到旧白底图会提示先生成透明版本。项目不再依赖 rembg / BiRefNet 或本地抠图模型，已有历史素材无需删除。

`COMIC_PROJECTS_DIR` 可指定独立项目目录，用于测试或其他工作区。`output/` 存放开发验证产物；应用默认不将其作为正式项目。

## 验证

后端行为测试不调用收费生成接口：

```powershell
.\.venv\Scripts\python.exe -m pip install pytest httpx
.\.venv\Scripts\python.exe -m pytest tests/test_studio.py -q
```

`scripts/validate_studio.py` 将示例项目复制到 `output/qa-projects/`，生成全部模板与预览图。`scripts/check_studio_browser.cjs` 为当前开发环境的浏览器联调脚本，使用 Edge 和本机 Playwright 依赖，默认检查 5174 / 8001 上的隔离测试服务。后端测试同时覆盖透明输出参数、透明图直接合成与旧白底场景生成新版本，不调用付费生图接口。

当前验证包含后端行为测试、前端构建、17 种模板渲染、桌面及手机宽度浏览器操作、图片下载及 PPTX 导出。覆盖了字体文件上传与读取、本格角色替换参考、透明贴图合成和旋转、贴纸保存恢复及旧长图下载拦截。浏览器联调另验证了艺术字设置、上传和移除标题图片、贴纸变换与四步导航。改图、专属角色参考和直接透明输出采用模型替身检查实际传参，未实际调用收费生图接口，模型生成的视觉效果仍需实际生成验收。


### 整体气泡素材

气泡库保留原有 10 款，并加入 14 款参考图样式。每款支持透明内底、白色内底和立体动画版本；气泡外围透明。箭头属于整体轮廓，不再提供单独拖动点。选中气泡后可旋转、水平/垂直翻转、拉伸和调整图层，文字框保持独立。

新增位图与立体素材在 `web/public/bubble-assets/`，原始参考图在 `web/public/bubble-references/`；迁移项目时保留这两个目录。`scripts/prepare_bubble_assets.py` 用于离线整理参考图和原始生成结果，日常运行不会再次生图或抠底。

### 多选、增删文字与结尾图文

画面精修中按住 Shift 点击文字和气泡即可多选，一起拖动；点击“组合”保存关联，之后单击组内任一元素可选中整组，“取消组合”恢复独立选择。“气泡轮廓”和“对话文字”按钮可以单独选中组内元素。支持添加文字框、气泡或两者，删除选中元素，每格最多 20 条。保存使用稳定的 `bubble_id`；`bubble_visible` / `text_visible` 分别控制轮廓和文字，`element_groups` 记录组合关系，重新合成与 PPTX 导出保留各层的独立性。

长图排版的结尾提示下可添加文字和图片内容块，调整顺序、对齐、字号或图片宽度，保存在 `long_layout.footer_blocks`。AI 生成结尾图片入口使用项目配置的图片服务，支持最多两张上传参考图、横图/方图/竖图和透明背景。生成通过后台任务执行，页面显示状态、错误与重试入口，成功后预览并点击“插入到结尾”。生图请求不自动重试，单次接口超时为 240 秒；任务结果保留素材编号，页面刷新后可恢复最近一次生成结果。图片保存到项目素材库，迁移时随项目文件一起保留。

### 分镜小标题样式

长图编辑器右侧的“分镜小标题”支持 18–72 px 字号、左/中/右对齐和自定义文字、背景颜色。七款样式包括无背景的简约文字、波浪下划线，以及有背景的方形底牌、圆角软糖、糖纸标签、波浪底牌、折角丝带。选择“所有分镜”设置默认效果，也可选择某一格单独调整；“恢复跟随全局”清除该格的设置，单格标题留空则隐藏标题。标题较长时自动换行并增加标题区高度，预览和导出使用同一套渲染。

所有长图模板均不再自动添加分镜序号，时间线使用圆点。已有长图需重新“保存排版并生成图片”后应用新样式。全局设置保存为 `long_layout.heading`，单格设置为 `long_layout.heading_overrides`，款式定义在 `schemas/heading_styles.json`。
